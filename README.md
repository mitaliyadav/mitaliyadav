## 🧪 Why a testing background matters for ML

Most ML failures are quality failures: bad data, silent regressions, unreproducible results. At Juniper I integrated 200+ automated test scripts into a Jenkins CI/CD pipeline and used anomaly detection and root cause analysis to improve data throughput by 25%. I bring that same mindset to every model I build: validate the data, test the behavior, automate the checks, and measure the results.
